# 🏠 Krisha ML — Real Estate Price Prediction

A web application built with **Streamlit** that uses a **CatBoost** machine learning model to estimate the market value of apartments in Kazakhstan based on real listings from **Krisha.kz**.

## ✨ Features

- Fast and accurate apartment price estimation
- Predicts price per square meter and total price
- User-friendly sidebar interface
- Trained on real market data from Kazakhstan
- Powered by CatBoost Regressor

## 🛠 Tech Stack

- **Python**
- **Streamlit** – Web interface
- **CatBoost** – Main ML model
- **Pandas & NumPy** – Data processing
- **scikit-learn** – Train/test split
